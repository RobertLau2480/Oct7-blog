# 关于项目

本项目是一个纯静态个人博客系统，核心目标是让 Markdown 内容在构建阶段直接打包到静态 HTML 中，浏览时无需额外调用文章接口，同时提供 SPA 体验和持续播放的背景音乐。

## 项目架构概览

- `content/`：所有文章源文件，使用 Markdown 编写。
- `static/`：静态资源目录，包括背景音乐、背景视频、图标和首页引言。
- `scripts/build.js`：构建脚本，将 `content/` 和 `static/` 中的数据注入到 `index.html` 模板，生成完整的 `public/` 输出目录。
- `scripts/serve.js`：本地预览服务，方便开发时查看构建结果。
- `public/`：构建结果目录，包含可直接部署的静态站点文件。
- `index.html`：页面模板与前端逻辑入口，运行时负责目录渲染、文章展示、主题切换、Giscus 评论等功能。

## 构建流程

构建过程中，`build.js` 会执行以下步骤：

1. 递归读取 `content/` 下的 Markdown 文件，生成目录树和文章内容映射。
2. 读取 `static/quotes.json` 作为首页随机引言。
3. 扫描 `static/bgm/` 生成背景音乐播放列表。
4. 将上述数据注入 `index.html` 模板，生成独立的 `public/` 页面。
5. 复制 `static/` 下的资源、`sw.js`、`404.html` 等文件到 `public/`。

最终生成的 `public/` 是一个完整的静态站点，浏览器访问时只需加载该目录下的文件即可。

## 运行原理

- 站点加载后，前端通过内嵌的 `window.__TREE__` 渲染左侧目录。
- 文章内容通过 `window.__FILES__` 获取，并在页面内部渲染为 HTML。
- 内部链接采用 SPA 路由，使用 `history.pushState` 进行文章切换，避免整页刷新。
- 背景音乐播放器使用单个 `<audio>` 元素，跨文章切换保持播放状态。
- 主题、背景、字体大小等用户设置保存在 `localStorage`，在刷新后自动恢复。

## 技术选型

- HTML + CSS：页面结构与样式。
- 原生 JavaScript：实现所有交互逻辑，无框架依赖。
- `marked.js`：将 Markdown 转换为 HTML。
- `mermaid`：渲染流程图与时序图。
- `KaTeX`：渲染数学公式。
- `Giscus`：提供评论区，基于 GitHub Discussions。
- Service Worker：缓存静态资源，提升加载性能。

## 部署方式

推荐的部署方式是将 `public/` 目录作为静态站点根目录部署到 Cloudflare Pages 或其他静态托管服务。

构建命令：

```bash
node scripts/build.js
```

输出目录：

```
public/
```
