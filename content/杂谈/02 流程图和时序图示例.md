# 流程图与时序图示例

本文展示博客对 **Mermaid 流程图**、**时序图** 以及 **数学公式** 的支持。

## 流程图

> [!tip] 提示
> 流程图使用 ` ```mermaid ` 代码块编写，支持 `graph`、`flowchart` 等关键字。

```mermaid
flowchart TD
    A[开始] --> B{是否周末？}
    B -- 是 --> C[睡懒觉 🛏️]
    B -- 否 --> D[起床搬砖 💼]
    C --> E[出门玩 🎮]
    D --> F[下班回家 🏠]
    E --> G[结束]
    F --> G
```

## 时序图

> [!info] 说明
> 时序图用于描述对象之间的消息交互顺序。

```mermaid
sequenceDiagram
    participant 用户 as 👤 用户
    participant 浏览器 as 🌐 浏览器
    participant 服务器 as 🖥️ 服务器
    participant 数据库 as 🗄️ 数据库

    用户->>浏览器: 点击文章链接
    浏览器->>服务器: GET /文章.html
    服务器->>数据库: 查询文章内容
    数据库-->>服务器: 返回 Markdown
    服务器-->>浏览器: 返回完整 HTML
    浏览器-->>用户: 渲染页面（SPA 不刷新）
```
